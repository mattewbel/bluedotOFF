# bluedotOFF test.24 — 연결 예시·진행바·홈·설정 정리

## 연결 준비

- 별도의 ‘완료한 단계 N개’ 줄과 생략 안내 줄을 제거했습니다. 현재 단계/11와 진행바가 한 터치 영역이며, 누르면 기존 적용 범위 창과 같은 둥근 모서리·테마 색·고정 닫기 버튼의 단계 목록을 엽니다.
- 진행바는 실제로 보고 있는 순서까지만 채웁니다. 2단계에서 개발자 옵션·Wi-Fi가 이미 켜져 있어도 뒤 칸을 먼저 채우지 않습니다. 단계 목록에서는 실제 준비 상태를 별도로 확인합니다. 기존 준비 단계 자동 생략은 유지합니다.
- 예시는 다음 화면의 조작 위치를 보여줍니다. 알림/근처 기기는 삼성 권한 창의 질문·허용·허용 안 함 형태, 개발자 옵션은 휴대전화 정보의 소프트웨어 정보와 빌드번호, Wi-Fi/무선 디버깅/코드 화면은 실제 누를 항목, 코드 입력은 알림 입력칸과 전송, 수동 입력은 분할 화면으로 표현합니다.
- 5단계 설명에 실제 ‘근처에 있는 기기를 찾아 연결하고 기기 간 상대적 위치를 파악’ 권한 문구와 ‘허용’을 명시했습니다. 앱 안의 예시는 설명 그림이며 실제 권한은 Android 창에서 선택합니다.
- 시작하기·자동 검사·자동 관리·적용 범위 같은 앱 내부 단계에는 불필요한 예시를 표시하지 않습니다. 10단계 이미지를 제거했고 도움말도 조작 예시만 표시합니다. 11단계 순서와 permission callback/페어링 동작은 유지합니다.
- 개인정보나 실제 코드가 없는 코드 기반 그림이며 새 의존성은 추가하지 않았습니다. OS 버전과 화면 크기에 따라 실제 배치는 다를 수 있습니다.

## 홈·설정

- 큰 상태 문구는 ‘bluedotOFF 적용완료’, 앱 수는 ‘N개 앱 bluedotOFF 적용중’입니다. 상세·목록·재적용 버튼 등 관련 문구와 쉬운 영어 번역도 맞췄습니다.
- 모든 숨김이 정상 완료된 경우 중복 결과 배너/성공 메시지를 제거했습니다. 오류·부분 실패·연결 종료 경고는 유지합니다. 정상 복원 안내의 기존 5초 표시도 유지합니다.
- 목록 행의 ‘마지막 확인 기준’, 재적용 필요·상태 확인 필요 판정은 유지합니다. 상시 연결이나 실시간 OFF 감시 기능이 생긴 것은 아닙니다.
- 홈의 적용 대상 제한 설명과 하단 연결 카드를 제거했습니다. 연결이 필요할 때의 상단 안내는 유지합니다.
- 설정의 ‘현재 적용 범위’와 선택한 범위를 같은 줄에, ‘재적용 알림’과 켜짐/꺼짐을 같은 줄 오른쪽에 표시합니다.
- 설정의 연결 항목은 수동 재연결·페어링 복구를 위해 필요하므로 ‘연결 관리’로 남겼습니다. 자동 연결이 준비되어 있으면 상태만 간단히 표시합니다. 연결 설정·읽기 진단·호환성 새로고침·수동 디버깅 종료 등은 고급 설정에서 접근할 수 있으며, 연결이 필요한 사용자는 바로 연결 설정 버튼이 나타납니다.

## 보존한 동작

SafetyEngine·permission flag/AppOps·UID/shared UID·Binder/reflection·native/helper·retry/delay·복원·롤백·test.22 대량 연결 재사용·test.23 목록 캐시/최종 스캔 정책을 변경하지 않았습니다. 실제 적용/복원 대상과 판정 조건을 바꾸지 않는 화면 수정입니다.

## 검증

- Debug/Release 빌드와 자동 검사 836개(core 310, 앱 Debug 263, Release 263)가 통과했습니다. 실패·오류·건너뜀은 0개입니다. Lint는 두 빌드 모두 오류 0개, 경고 41개이며 경고를 숨기지 않았습니다.
- APK 서명·매니페스트·16KB ELF/ZIP 정렬·고정 loopback 연결·좁은 FINE 표시 비트 setter 정적 검사를 통과했습니다. 정적 검사는 해당 패턴과 구성의 확인이며 전체 동작의 수학적 증명은 아닙니다.
- Fold7에 최종 Debug APK를 업데이트 설치했습니다. 실제 홈·설정·읽기 전용 연결 검사·진행바 터치·앱 테마의 단계 목록과 닫기/홈 복귀를 확인했습니다.
- 설치 전후와 검증 종료 시 등록 94개의 원복 기록이 바이트 단위로 동일했습니다. 페어링/설정 파일과 모든 등록 앱의 FINE flags도 동일했고, 검증 구간의 대상 setter 이벤트는 0회였습니다. 기존 자동 연결의 무선 디버깅 ON/OFF는 정상 종료됐습니다.
- 홈은 기존 상태 그대로 93개 적용중·1개 재적용 필요를 표시했습니다. 1개 재적용 필요는 설치 전부터 있던 상태이며 이번 화면 검증에서 재적용하거나 복원하지 않았습니다.
- 초기화 없이 진행했으므로 최초 설정의 실제 OS 권한 창·새 코드 페어링 전체 11단계는 이번에 재시험하지 않았습니다. 미래 준비 단계가 켜진 2단계 진행바, 예시 표시/제거, 단계 팝업, 정상/오류 완료 안내, 설정 배치는 자동 화면 검사로 확인했습니다. 한국어/영어 안내 그림은 렌더링 결과를 검수했습니다.
- 최종 APK: `artifacts/bluedotOFF-1.0.0-test.24.apk` / `artifacts/bluedotOFF-1.0.0-test.24-release.apk`. 빌드 검사 결과는 `artifacts/build-audit-1.0.0-test.24.json`에 있으며, 개인 기기 화면·원복 기록은 Git 제외 영역에만 보관했습니다. 공개 업로드는 수행하지 않았습니다.
